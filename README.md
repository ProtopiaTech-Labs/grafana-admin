# Grafana OSS dla Administratorów — pliki do ćwiczeń

Dashboardy startowe, skrypty i pliki provisioningu do ćwiczeń kursu.

```bash
git clone https://github.com/ProtopiaTech-Labs/grafana-admin.git materialy
cd materialy
```

Komendy z ćwiczeń uruchamiasz w katalogu `materialy`: ścieżki `pliki/<plik>` są względne wobec niego.

- `pliki/` — pliki ćwiczeń; prefiks `NN-` to numer modułu.
- `lab/application-alerts.yaml` — reguły `PrometheusRule` Labu wspólnego (moduł 7).

Repozytorium jest generowane automatycznie; zmiany w nim zostaną nadpisane przy kolejnej publikacji.
